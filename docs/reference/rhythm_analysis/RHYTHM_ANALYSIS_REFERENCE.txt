1. OVERVIEW
================================================================================

The Rhythm Analysis module provides 10 different methods for detecting and
analyzing circadian rhythms in time-series data:

| Method           | Type          | Best For                              |
|------------------|---------------|---------------------------------------|
| JTK Cycle        | Nonparametric | Robust detection, evenly sampled data |
| AR-JTK           | Nonparametric | Data with autocorrelated noise        |
| Cosine-Kendall   | Nonparametric | Similar to JTK, cosine templates      |
| Cosinor OLS      | Parametric    | Standard rhythm characterization      |
| Harmonic Cosinor | Parametric    | Bimodal/multimodal rhythms            |
| Fourier F24      | Effect size   | Screening, not significance testing   |
| Lomb-Scargle     | Periodogram   | Unevenly sampled data                 |
| CWT              | Time-frequency| Non-stationary rhythms                |
| Spectral Analysis| Periodogram   | Period detection via FFT              |
| LME              | Mixed model   | Hierarchical/grouped data             |

Dependencies:
    pip install numpy scipy pandas statsmodels
    pip install PyWavelets  # Optional, for CWT only

-------------------------------------------------------------------------------
3.1 JTKResult
-------------------------------------------------------------------------------
Used by: JTK Cycle, AR-JTK, Cosine-Kendall

Attributes:
    p_value         : float   - Raw p-value of the best template (Kendall tau test)
    bonf_p_value    : float   - p_value × n_tests (Bonferroni over all templates)
    bh_p_value      : float   - p_value × n_tests / k, k = rank of the best template's
                                p-value among all templates; k = 1 unless several tie,
                                so it almost always equals bonf_p_value (not a BH
                                step-up adjustment)
    adj_p_value     : float   - Alias of bh_p_value (backward compatibility)
    period          : float   - Best-fit period (hours)
    amplitude       : float   - Estimated amplitude (90th-10th percentile / 2)
    acrophase       : float   - Peak time in hours
    asymmetry       : float   - Waveform asymmetry parameter (0-1)
    tau             : float   - Kendall tau correlation coefficient
    lag             : float   - Phase lag parameter (time of the template minimum)
    n_tests         : int     - Number of period × lag × asymmetry templates tested
    method          : str     - Analysis method identifier
    pvalue_method   : str     - "analytical" or "empirical"; with "empirical" the
                                three p-values are the same permutation p-value
    best_fit        : Optional[bool] - Set by the *_all_periods sweeps only: True
                                for the period with the smallest unrounded p-value

Methods:
    is_significant(alpha=0.05, method='bh') -> bool : bh / bonferroni / raw p < alpha
    to_dict() -> Dict[str, Any]         : Convert to dictionary

    amplitude       : float   - Rhythm amplitude
    acrophase_rad   : float   - Acrophase in radians

-------------------------------------------------------------------------------
4.1 JTK Cycle (_run_discrete_jtk)
-------------------------------------------------------------------------------

Description:
    Nonparametric rhythm detection using Kendall's tau correlation with
    triangle waveform templates. Tests multiple periods and phase shifts.

Function Signature:
    _run_discrete_jtk(
        series: pd.Series,
        period_range: List[float] = None,
        lag_range: Optional[np.ndarray] = None,
        asymmetries: List[float] = None,
        n_permutations: int = 0,
        seed: int = 42
    ) -> JTKResult

Parameters:
    series         : pd.Series with time as index, values as data
    period_range   : List of periods to test (default: [20, 21, ..., 28])
    lag_range      : Array of lag/phase values to test (default: 0 to period, 1 h steps)
    asymmetries    : List of asymmetry values (default: [0.5] for symmetric)
    n_permutations : > 0 for an empirical p-value (Hutchison et al., 2015): null
                     distribution of the max |tau| over all templates for permuted
                     data (Phipson & Smyth +1 correction). 0 = analytical.
    seed           : RNG seed for the permutations

Returns:
    JTKResult object

Algorithm:
    1. Rank-transform the data
    2. For each (period, lag, asymmetry) combination:
       - Generate triangle template aligned to timepoints (minimum at the lag,
         peak at lag + asymmetry × period)
       - Compute Kendall's tau between ranked data and template
    3. Select best combination (lowest p-value)
    4. Acrophase = lag + asymmetry × period if tau > 0; lag if tau < 0 (the data
       peak at the template minimum)
    5. Correct p for the n_tests templates (Bonferroni; see bh_p_value in 3.1), or
       compute the empirical p-value

Period sweeps:
    _run_discrete_jtk_all_periods(series, period_range, lag_range, asymmetries,
                                  n_permutations=0, seed=42) -> List[JTKResult]
    One result per period (its best template); the corrections, and with
    n_permutations > 0 the null distribution, cover all the templates of the
    whole range. best_fit marks the period a single run would report.

-------------------------------------------------------------------------------
4.2 AR-JTK (_run_ar_jtk)
-------------------------------------------------------------------------------

Description:
    JTK with autoregressive noise handling. Detects autocorrelation in the
    rank residuals and pre-whitens the ranked series before re-running JTK.

Function Signature:
    _run_ar_jtk(
        series: pd.Series,
        period_range: List[float] = None,
        lag_range: Optional[np.ndarray] = None,
        asymmetries: List[float] = None,
        ar_lag: int = 1,
        ljungbox_lag: int = 10,
        force_prewhiten: bool = False,
        n_permutations: int = 0,
        seed: int = 42
    ) -> Tuple[JTKResult, bool]

Parameters:
    series          : pd.Series with time as index (in time order), values as data
    period_range    : List of periods to test
    lag_range       : Array of lag values
    asymmetries     : List of asymmetry values
    ar_lag          : AR model order for prewhitening (default: 1)
    ljungbox_lag    : Lag for Ljung-Box autocorrelation test (default: 10)
    force_prewhiten : Skip the Ljung-Box test and always prewhiten
    n_permutations  : Empirical p-values (see 4.1), on the prewhitened series

Returns:
    Tuple of (JTKResult, bool indicating if AR correction was applied)

Algorithm (step 1-4 in _ar_prewhitened_ranks):
    1. Run initial JTK analysis on the original series
    2. Regress the ranks of the data on the best-fitting template; residuals
    3. Ljung-Box test on the residuals (series shorter than ljungbox_lag + 1
       points count as white noise); skipped with force_prewhiten
    4. If autocorrelated: fit AR(ar_lag) to the residuals and apply that filter
       to the ranked series, r_t − Σ φ_j r_{t−j} (first ar_lag points dropped).
       The template is NOT added back.
    5. Re-run JTK on the prewhitened series: p-values (and n_tests) from it;
       period, acrophase, tau, lag, asymmetry from step 1; amplitude from the
       original data

Calibration (48 hourly points, 400 null series per scenario, p < 0.05):
    forced prewhitening 1.5 % white noise, 7.5 % AR(1) φ = 0.7
    (plain JTK: 0.3 % and 30 %). The former version, which rebuilt the series
    around the best template, gave 18 % and 100 %.

4.3 Cosine-Kendall (_run_cosine_kendall)
-------------------------------------------------------------------------------

Description:
    Similar to JTK but uses cosine templates instead of triangle templates.
    Fully nonparametric using Kendall's tau correlation.

Function Signature:
    _run_cosine_kendall(
        series: pd.Series,
        period_range: List[float] = None,
        interval: float = 1.0,
        n_permutations: int = 0,
        seed: int = 42
    ) -> JTKResult

Parameters:
    series         : pd.Series with time as index, values as data
    period_range   : List of periods to test (default: circadian range)
    interval       : Time interval for lag steps (default: 1.0)
    n_permutations : Empirical p-values (see 4.1)

Returns:
    JTKResult object (method = "Cosine-Kendall")

Algorithm:
    1. Rank-transform the data
    2. For each (period, lag) combination:
       - Generate cosine template: cos(2π(t-lag)/period)
       - Rank the template
       - Compute Kendall's tau
    3. Select best combination, apply the corrections of 4.1
    4. Acrophase = lag if tau > 0; lag + period/2 if tau < 0

Period sweeps: _run_cosine_kendall_all_periods(series, period_range, interval,
    n_permutations=0, seed=42), as in 4.1.

4.4 Cosinor OLS (_fit_cosinor)
-------------------------------------------------------------------------------

Description:
    Standard parametric cosinor analysis using Ordinary Least Squares.
    Fits: y = mesor + amplitude * cos(2πt/T - acrophase)

Function Signature:
    _fit_cosinor(
        times: np.ndarray,
        values: np.ndarray,
        period_range: List[float] = None
    ) -> CosinorResult

Parameters:
    times        : Array of time values (hours)
    values       : Array of measurement values
    period_range : List of periods to test (default: circadian range)

Returns:
    CosinorResult object

Algorithm:
    1. For each period in range:
       - Construct design matrix: [1, cos(ωt), sin(ωt)]
       - Fit OLS regression
       - Calculate AIC for model selection
    2. Select best period (lowest AIC)
    3. Calculate amplitude = √(β_cos² + β_sin²)
    4. Calculate acrophase = atan2(β_sin, β_cos)
    5. Compute confidence intervals using delta method:
       Var(A) = (β_cos² Var(β_cos) + β_sin² Var(β_sin) + 2 β_cos β_sin Cov) / A²
       Var(φ) = (β_sin² Var(β_cos) + β_cos² Var(β_sin) − 2 β_cos β_sin Cov) / A⁴
       (the acrophase CI is wrapped to [0, 2π), see 3.2)
    6. adj_p_value = p_value × number of periods tested (Bonferroni)

Model:
    y = M + β_cos*cos(ωt) + β_sin*sin(ωt)
    where ω = 2π/period, amplitude = √(β_cos² + β_sin²)
    and acrophase = atan2(β_sin, β_cos)

4.5 Harmonic Cosinor (_fit_harmonic_cosinor)
-------------------------------------------------------------------------------

Description:
    Detects multi-modal rhythms (e.g., bimodal with 2 peaks per cycle)
    with an OLS cosinor that includes the fundamental and its harmonics.

Function Signature:
    _fit_harmonic_cosinor(
        times: np.ndarray,
        values: np.ndarray,
        period_range: List[float] = None,
        n_harmonics: int = 2
    ) -> HarmonicCosinorResult

Parameters:
    times        : Array of time values
    values       : Array of measurement values
    period_range : List of periods to test (default: 20-28 h in 0.5 h steps)
    n_harmonics  : Number of harmonics (1=unimodal, 2=bimodal, etc.; GUI: 1-6)

Returns:
    HarmonicCosinorResult object

Model:
    y = M + Σ_k [β_k,cos cos(kωt) + β_k,sin sin(kωt)],  k = 1..n_harmonics, ω = 2π/period

Algorithm:
    1. For each period: fit the model by OLS; keep the period with the highest R²
       (same number of parameters at every period, so also the lowest AIC)
    2. Overall F-test (H0: all coefficients except the intercept are zero);
       adj_p_value = p × number of periods fitted
    3. If n_harmonics > 1: F-test of the full model against one harmonic
       (warning if p > 0.05)
    4. Per harmonic k: A_k = √(β_k,cos² + β_k,sin²); acrophase = atan2(β_k,sin,
       β_k,cos) · period / (2πk), the first of its k peaks per cycle
    5. Peaks, troughs and half peak-to-trough range of the fitted curve (sum of
       all harmonics) over one cycle, on a 30-s grid

4.6 Fourier F24 (_compute_fourier_f24)
-------------------------------------------------------------------------------

Description:
    Computes F24 score (Wijnen et al., 2006) - an effect size measure
    representing power at target frequency relative to noise.

    NOTE: This is NOT a significance test. Use for screening/filtering.

Function Signature:
    _compute_fourier_f24(
        times: np.ndarray,
        values: np.ndarray,
        target_period: float = 24.0,
        n_permutations: int = 1000
    ) -> FourierF24Result

Parameters:
    times          : Array of time values
    values         : Array of measurement values
    target_period  : Period to evaluate (default: 24 hours)
    n_permutations : Number of random permutations for baseline

Returns:
    FourierF24Result object

Algorithm:
    1. Center data (subtract mean)
    2. Compute FFT
    3. Find power at target frequency
    4. Generate permuted data n times
    5. Compute mean permutation power at target frequency
    6. F24 = target_power / mean_permutation_power
    7. f24_norm = 2 · target_power / Σ(y − ȳ)²  (1 for a pure sinusoid)
    8. p_f24 = (1 + #{permuted power ≥ target_power}) / (1 + n_permutations)

Interpretation:
    Use p_f24 for the rhythmic call (the GUI Notes column uses pF24 < α);
    a fixed f24_score threshold is only comparable between designs with the
    same number of time points.

4.7 Lomb-Scargle (_compute_lomb_scargle)
-------------------------------------------------------------------------------

Description:
    Periodogram method designed for unevenly sampled data.
    Computes power spectrum and estimates false alarm probability.

Function Signature:
    _compute_lomb_scargle(
        times: np.ndarray,
        values: np.ndarray,
        period_range: Tuple[float, float] = (18.0, 32.0),
        n_periods: int = 1000
    ) -> LombScargleResult

Parameters:
    times        : Array of time values (can be unevenly spaced)
    values       : Array of measurement values
    period_range : (min_period, max_period) tuple
    n_periods    : Number of periods to evaluate

Returns:
    LombScargleResult object

Algorithm:
    1. Center data
    2. Define period grid from min to max
    3. Convert to angular frequencies
    4. Compute Lomb-Scargle periodogram (scipy.signal.lombscargle)
    5. Find dominant period (highest power)
    6. Estimate FAP ≈ 1 - (1 - exp(-power))^M

4.8 CWT - Continuous Wavelet Transform (_compute_cwt)
-------------------------------------------------------------------------------

Description:
    Time-frequency analysis using wavelet transforms. Useful for detecting
    non-stationary rhythms with varying period or amplitude over time.

    Requires PyWavelets: pip install PyWavelets

Function Signature:
    _compute_cwt(
        times: np.ndarray,
        values: np.ndarray,
        sampling_interval: float = 0.5,
        wavelet: str = 'cmor1.5-1.0',
        period_range: Tuple[float, float] = (20.0, 28.0)
    ) -> CWTResult

Parameters:
    times             : Array of time values
    values            : Array of measurement values
    sampling_interval : Sampling interval in hours
    wavelet           : Wavelet type (default: complex Morlet)
    period_range      : (min_period, max_period) tuple

Returns:
    CWTResult object

Raises:
    ImportError if PyWavelets is not installed

Algorithm:
    1. Detrend signal (subtract mean)
    2. Define scales from period range
    3. Apply CWT using specified wavelet
    4. Compute power = |coefficients|²
    5. Calculate global wavelet spectrum (mean over time)
    6. Find dominant period
    7. Track period variation over time
    8. Detect amplitude modulations

Wavelet Options:
    'cmor1.5-1.0' : Complex Morlet (default, good for oscillations)
    'morl'        : Real Morlet
    'mexh'        : Mexican Hat
    See PyWavelets documentation for more options

4.9 Spectral Analysis (run_spectral_analysis in RhythmAnalyzer)
-------------------------------------------------------------------------------

Description:
    FFT-based spectral analysis with multiple periodogram methods.
    Returns data for interactive visualization.

Method Signature (RhythmAnalyzer class):
    run_spectral_analysis(
        variable: str,
        condition: str,
        per_type: str = 'per',
        max_per: float = 240.0,
        prominent: bool = True
    ) -> Dict[str, Any]

Parameters:
    variable  : Name of variable to analyze
    condition : Condition to analyze
    per_type  : Periodogram type:
                - 'per'        : Standard FFT periodogram
                - 'welch'      : Welch's method (averaged)
                - 'lombscargle': Lomb-Scargle periodogram
    max_per   : Maximum period to consider (hours)
    prominent : Whether to identify prominent peaks

Returns:
    Dictionary with keys:
        'periods'          : np.ndarray - Period values
        'power'            : np.ndarray - Power spectral density
        'threshold'        : float      - Significance threshold
        'dominant_period'  : float      - Period with highest power
        'significant_peaks': List[float] - Periods above threshold

Significance Threshold:
    Based on Refinetti et al. (2007), with Fisher's (1929) number of Fourier
    frequencies m = max(2, (N - 1) // 2):
    T = (1 - (0.05/m)^(1/(m-1))) × Σ(power over non-zero frequencies)
    For 'lombscargle' (always mean-centred; periods from the Nyquist period of
    the median sampling interval, at least 2 h, to max_per):
    T = (1 - (0.05/m)^(1/(m-1))) × Σ(y - ȳ)² / 2

Description:
    Linear Mixed Effects model for hierarchical/grouped data with
    repeated measurements (e.g., multiple subjects).

Function Signature:
    _fit_lme_model(

        fixed_effects: List[str],
        random_effect: str
    ) -> LMEResult

Parameters:

    dependent ~ fixed_effect1 + fixed_effect2 + ... | random_effect

        dependent='expression',
        fixed_effects=['time'],
        random_effect='subject'
