1. MOTIVATION
--------------------------------------------------------------------------------

The CRS-AI features were extracted at training time with fixed sub-method
search windows: JTK_CYCLE and Cosinor OLS 20-28 h, Lomb-Scargle 18-32 h,
F24 at 24 h, JTK asymmetry 0.5. A user period_range is honored only if it
overlaps the training window [18, 32] h by more than 1 h (clipped to it if
it spills out, training defaults otherwise), and it is then applied to
JTK and Cosinor; Lomb-Scargle always keeps its training range. Until
2026-10-22 the range also bounded Lomb-Scargle, so a default GUI run
(pre-filled 20-28 h) did not reproduce the training features; the
'22-26, LS too' column re-creates that policy for comparison. This file
quantifies the cost of a user range on the published holdout.


2. EXPERIMENTAL DESIGN
--------------------------------------------------------------------------------

  - The 1117 published holdout series (holdout_predictions.csv) are
    recovered from regenerated training instances; their DEFAULT features
    equal the cached X_test.npy bit-for-bit and their DEFAULT
    probabilities reproduce holdout_predictions.csv.
  - Features are re-extracted under GUI 20-28 (period_range = (20, 28) h,
    which must reproduce DEFAULT), NARROW 22-26 (period_range = (22, 26) h;
    JTK and Cosinor change) and '22-26, LS too' (the previous policy: the
    same range also applied to Lomb-Scargle).
  - The same released model scores every feature matrix.
